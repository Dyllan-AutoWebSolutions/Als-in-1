# Als-in-1 Tuindienste — website

Client site built by AutoWeb Solutions. Garden services for homes and farms in Worcester and the Hex River Valley, Western Cape. These rules apply to every session in this repo.

## Source of truth

| What | Where | Rule |
| --- | --- | --- |
| Layout, section order, copy | `reference/mockups-static/*.html` (open in a browser) + `reference/screenshots/` | Client-approved. Match it. Don't add, drop or reorder sections without asking. |
| Original canvas files | `reference/mockups-canvas-source/*.dc.html` | Same content as the static mockups, in the canvas editor's format. Reference only. |
| Colours, type, spacing, radii, shadows | `reference/design-system/tokens.json` | The only allowed values. Never invent a colour or size. |
| Brand rules (voice, logo, imagery, contrast) | `reference/design-system/README.md` | Read before writing CSS or copy. |
| Logo | `assets/logo/als-in-1-logo.png` (transparent PNG, 1111×960) | Only on cream, paper or white. Never on brown or dark grounds. Min width 140px. |
| Unfilled client info | `content/placeholders.md` | Every `[BRACKET]` on the site is listed here. |
| AI image slots | `content/image-prompts.md` | Filenames, sizes and prompts. |

Note: the screenshots were rendered without web fonts, so headings show a fallback sans. The real fonts are Josefin Sans and Nunito Sans.

## Stack (fixed)

- Hand-coded HTML, CSS and vanilla JS. No framework, no CMS, no build step, no Tailwind.
- Hosting: Netlify, deployed from Git. Forms: Netlify Forms.
- Fonts: self-hosted woff2. Josefin Sans 600 (display), Nunito Sans 400 and 700 (body).

## Language

- The whole site is in **Afrikaans** (`<html lang="af">`). There's no English version.
- Copy comes verbatim from the mockups. Don't rewrite, translate or "improve" it. If something reads wrong, flag it in your report instead.
- Code comments and commit messages are in English.

## Non-negotiables

- **Tokens:** `css/tokens.css` is generated by hand from `tokens.json`, one CSS custom property per token. All other CSS uses `var(--token)`, never raw hex.
- **Contrast:** `leaf`, `ochre` and `sun` are fills only, never text colour. Text on them is `--ink`. Green text and buttons use `--leaf-deep`, and only for WhatsApp and success states.
- **No fake proof.** Reviews, farm logos, the stats band and the Voor/Na (before/after) sections are built but ship with the `hidden` attribute, plus an `<!-- UNHIDE WHEN: … -->` comment, until the client supplies real content. AI images must never appear as before/after shots of real jobs.
- **Accessibility:**
  - Real `<a>` and `<button>` elements; labelled inputs; FAQ built with `<details>`/`<summary>`.
  - Visible focus ring: 2px `--focus-ring`, 2px offset.
  - Touch targets at least 44px; body text at least 16px on mobile.
- **Performance:**
  - Images in WebP with explicit width and height; lazy-load everything below the fold.
  - No JS required to read the site.
  - Target Lighthouse mobile ≥ 95 on performance, accessibility, best practices and SEO.
- **Placeholders** stay as visible `[BRACKETS]` so they're grep-able. The WhatsApp number is the literal `27000000000` everywhere, for a single find-and-replace later.

## Commands

- Local preview: `npx serve .` (or `python -m http.server`).
- Commit after each phase with a clear message. Don't push or deploy unless asked.
