# Als-in-1 Tuindienste: build hand-off

1. Unzip this folder where the repo should live, e.g. `als-in-1-tuindienste/`.
2. Open Claude Code in that folder. It reads `CLAUDE.md` automatically.
3. Paste the contents of `BUILD-PROMPT.md` as the first message.

| Path | What |
| --- | --- |
| `CLAUDE.md` | Standing rules for every Claude Code session in this repo |
| `BUILD-PROMPT.md` | Kick-off prompt: phases, specs, QA, report |
| `reference/mockups-static/` | Approved mockups as plain HTML. Open `index.html` in a browser; the nav links work |
| `reference/screenshots/` | Desktop (1440) and mobile (390) renders of each page, with fallback fonts |
| `reference/mockups-canvas-source/` | Original canvas files (reference only) |
| `reference/design-system/` | `tokens.json`, brand README, component CSS |
| `assets/logo/` | Transparent PNG logo |
| `content/placeholders.md` | Everything the client still has to supply |
| `content/image-prompts.md` | AI image filenames, sizes and prompts |
